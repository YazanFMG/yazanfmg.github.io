## 📦 How to Publish to GitHub Pages in 2 Minutes

### Method A: User Site (`https://yazanfmg.github.io`) — **Recommended**

1. Go to [GitHub](https://github.com/new) and create a **new public repository** named:
   ```text
   yazanfmg.github.io
   ```
   *(Replace `yazanfmg` with your exact GitHub username if different)*

2. In your local terminal inside this `yazan-portfolio` folder, run:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Game dev portfolio"
   git branch -M main
   git remote add origin https://github.com/yazanfmg/yazanfmg.github.io.git
   git push -u origin main
   ```

3. Your website will be live automatically at `https://yazanfmg.github.io` within 1-2 minutes!

---

### Method B: Project Site (`https://yazanfmg.github.io/portfolio`)

1. Create a repository named `portfolio` on GitHub.
2. Push the files:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/yazanfmg/portfolio.git
   git push -u origin main
   ```
3. In your repo on GitHub:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Branch: `main`, Folder: `/ (root)`.
   - Click **Save**.
