Graduation Project · Android Security Suite

CyberGuard Mobile — Consumer Threat & Phishing Defense

An Android utility designed to help everyday and non-technical users spot background permission abuse, inspect deceptive URLs, and assess suspicious emails.

View on GitHub
Why I Built It

I noticed people around me—especially family and older users—often fall victim to deceptive phishing links, suspicious SMS prompts, or sideloaded apps with excessive background permissions. Security software is usually full of jargon they don't understand, so I wanted to build an all-in-one Android utility that breaks down complex system risk into clear, actionable guidance.

My Contribution — What I Personally Built

I architected and built the full mobile client in Flutter and Dart, including the native Kotlin MethodChannel integrations. I implemented the Android permission auditing engine that inspects installed packages, flags dangerous permission combinations (e.g. background data + SMS + camera), wrote the real-time link inspector, and integrated on-device AES-256 encrypted storage.

Teammate's Contribution

The phishing email NLP classifier was trained and provided by my graduation project teammate, integrated into the app via our shared backend API endpoint. The on-device analysis pipeline and UI were my work; the ML model training was his.

Detection & Analysis Architecture
Android Device → Package & Permission Audit → Risk Heuristics → URL / Phishing Checks → Security Score → Actionable User Guidance
Platform Limitations & Honest Reflection:

Some Android security checks depend directly on OS-level restrictions and permission visibility, meaning coverage varies depending on OEM customizations and specific Android API versions. Background traffic inspection measures aggregate data volume rather than live deep packet inspection due to unrooted userland constraints.

Local AI NPC System — Speech-to-Speech Voice Pipeline

Connecting Unreal Engine 5 with local speech recognition, an on-device LLM, and text-to-speech for real-time conversational game characters.

Real Architecture (No Cloud Latency)

Instead of relying on cloud APIs with per-call charges and unpredictable latency, this project connects Unreal Engine 5 directly to local AI models. Players speak naturally through a microphone, and the NPC answers with synthesized voice audio and matching runtime lip-sync animations.

Pipeline Data Flow
Microphone → Whisper (STT) → Local LLM Brain → Piper (TTS) → UE5 Lip Sync
Engineering Challenge

Managing asynchronous audio capture and JSON payload streaming without stuttering or blocking the game rendering thread. The character state machine dynamically switches between listening, thinking, and speaking states.

The path connecting rapid game jams to defensive security engineering.

My path started with rapid game development and game jams, learning how systems break when pushed to their limits, how memory leaks happen, and how software behaves under stress. That mindset naturally guided me toward defensive security, malware auditing, and endpoint protection.
