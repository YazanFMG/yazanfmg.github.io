UE5 AI-Powered NPC Brain

An advanced, zero-latency AI NPC cognitive framework built in Unreal Engine 5. Players converse naturally with in-game characters using real-time voice input. The system combines local AI inference, live speech recognition (STT/TTS), and dynamic world context injection to trigger reactive animations and quest state changes.

System Architecture & Core Mechanics
  • Voice-to-Text Pipeline (STT): Captures player microphone audio in real-time, converting speech to structured text tokens.
  • Dynamic World Context Injection: Feeds player inventory items, current quest objectives, nearby actors, and historical dialogue into the prompt buffer.
  • Local AI Processing & Low Latency: Executes lightweight local LLM reasoning without relying on slow external web APIs.
  • Text-to-Speech & State Triggers: AI voice synthesis synchronizes with NPC mouth blendshapes and animates custom reactions.

CyberGuard Mobile

Comprehensive Android Security & Anti-Phishing Application • Graduation Project

GitHub Repository

A multi-layered Android security application built with Flutter and Dart designed to protect non-technical users from credential harvesting, malicious links, and spyware. Integrates local heuristics, external threat intelligence APIs, and a custom NLP BERT machine learning model.

3-Stage Phishing & URL Scanner

1. Local structural heuristics (IP host, typosquatting TLDs, HTTP vs HTTPS).

2. Live threat intelligence (Google Safe Browsing & VirusTotal APIs).

3. Custom fine-tuned BERT Model on Hugging Face Spaces for email phishing detection via OAuth2 token integration.

k-Anonymity Breach Checker

Verifies whether user passwords exist in public breach databases (Have I Been Pwned) without ever transmitting the full password. Hashes locally with SHA-1 and sends only a 5-character prefix to guarantee complete zero-knowledge privacy.

Encrypted Database & Keystore

Secures sensitive application configurations and logs using AES-256-CBC backed by hardware-level Android Keystore and encrypted Hive NoSQL database storage.

Dynamic Link Interceptor

Catches Android Intents (WhatsApp, SMS, browser taps) using GoRouter deep linking to automatically inspect destination URLs before launching them in the default browser.

Spyware & Permission Auditor

Scans installed APK permissions against high-risk surveillance combinations (e.g. RECORD_AUDIO + READ_SMS + ACCESS_FINE_LOCATION) to warn users about stalkerware.

Emergency Lockdown Module

One-touch rapid response module to terminate networked processes, flush temporary memory caches, and force re-authentication on critical accounts during suspected breaches.
