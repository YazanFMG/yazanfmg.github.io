Graduation Project · Android Security Suite

CyberGuard Mobile — Consumer Threat & Phishing Defense

An Android utility designed to help everyday and non-technical users spot background permission abuse, inspect deceptive URLs, and assess suspicious emails.

View on GitHub
Why I Built It

I noticed people around me—especially family and older users—often fall victim to deceptive phishing links, suspicious SMS prompts, or sideloaded apps with excessive background permissions. Security software is usually full of jargon they don't understand, so I wanted to build an all-in-one Android utility that breaks down complex system risk into clear, actionable guidance.

My Contribution — What I Personally Built

I architected and built the full mobile client in Flutter and Dart, including the native Kotlin MethodChannel integrations. I implemented the Android permission auditing engine that inspects installed packages, flags dangerous permission combinations (e.g. background data + SMS + camera), wrote the real-time link inspector, and integrated on-device AES-256 encrypted storage.

Teammate's Contribution

The phishing email NLP classifier was trained and provided by my graduation project teammate, integrated into the app via our shared backend API endpoint. The on-device analysis pipeline and UI were my work; the ML model training was his.

Detection & Analysis Architecture
Android Device → Package & Permission Audit → Risk Heuristics → URL / Phishing Checks → Security Score → Actionable User Guidance
Platform Limitations & Honest Reflection:

Some Android security checks depend directly on OS-level restrictions and permission visibility, meaning coverage varies depending on OEM customizations and specific Android API versions. Background traffic inspection measures aggregate data volume rather than live deep packet inspection due to unrooted userland constraints.

Desktop Application · Electron & Node.js

Aura Player — Desktop Media Player & Streamer

A lightweight, customizable desktop player blending local audio/video format playback with a Blender-style zoom/pan viewport and direct YouTube stream extraction.

Why I Built It

Most default media players feel either heavy or lack precise scrubbing and zoom controls when reviewing game recordings and animation frames. I wanted a clean desktop tool that supports middle-mouse viewport panning like Blender, zero-latency keyboard shortcuts, and stream extraction.

Key Engineering Feats
  • Blender-Style Viewport Math: Boundary-clamped zoom and middle-mouse drag-to-pan transforms that eliminate black-border drift.
  • Integrated YouTube Pipeline: Built-in webview with automated stream URL extraction via yt-dlp.
  • Audio Visualizer Mode: Automatic fallback to an interactive vinyl disc simulation with live equalizer animations.
  • Native Windows Integration: Packaged via custom NSIS installer with registry-level file type icon associations.
Architecture Highlights
Electron Multi-Process: Context-isolated ipcMain / ipcRenderer security model.
Formats: MP4, MKV, AVI, MOV, WebM, MP3, WAV, FLAC, Subtitle loading (.srt, .vtt).
Controls: Frame-by-frame stepping, 0.1x - 16x variable speed, PiP mode.
Desktop Application · Electron & Node.js

Creator Studio PRO — Desktop Video Overlay & Dynamic Speech Suite

A desktop workflow utility that automates social media graphics, speech-synced typography, and broadcast-grade transparent video overlays for video editors.

Why I Built It

Creating animated social media pop-ups and timed speech subtitles in editors like Premiere Pro is manually repetitive. I built a dedicated Electron app that ingests YouTube data, runs real-time 60 FPS motion canvas physics, transcribes audio locally with Whisper, and renders alpha video that drags directly into editor timelines.

Core Architecture & Features
  • 60 FPS Canvas Motion Physics: Custom mathematical formulas for spring dampening, elastic bounce, and interactive drag-to-position preview.
  • Whisper ASR & Waveform Alignment: Bilingual speech-to-text (Arabic & English) with Web Audio API waveform peak visualization and energy onset detection.
  • Headless Alpha Video Pipeline: Transparent Chromium rasterizer paired with FFmpeg to encode ProRes 4444 and WebM with alpha channels.
  • Native NLE Drag-and-Drop: Integrated OS-level webContents.startDrag allowing editors to drag rendered clips straight onto their video timeline.
  • OS-Level Credential Protection: YouTube Data API keys encrypted at rest via Electron safeStorage (Windows DPAPI).
Tech Stack & Protocols
Runtime: Electron, Node.js, Chromium
Frontend: Vanilla ES6+, HTML5 Canvas 2D, Web Audio API
Rendering: FFmpeg (ProRes 4444 yuva444p10le, WebM VP9)
AI & Speech: Whisper ASR, Client-side RMS Onset Detection
Security: Context-isolated contextBridge, DPAPI encryption
