01 / Primary Focus

Cybersecurity & Defensive Engineering

Evidence-driven security work: an end-to-end mobile threat defense system and industry certification.

Why I Built This

I noticed many people around me—especially older and less tech-savvy users—regularly fall victim to deceptive links, phishing emails, or unknowingly install sideloaded apps running intrusive background permissions and heavy data traffic. I wanted to build an all-in-one Android utility that breaks down complex system risk into clear, actionable summaries anyone can understand.

What I Built (My Role)

Designed and developed the full mobile client application using Flutter & Dart. Built the Android permission auditing engine that queries installed packages, classifies high-risk permissions (SMS, Camera, Contacts, Background Data), and flags unusual background data usage. Built the link inspector and integrated a dedicated on-device/Hugging Face phishing classifier pipeline to scan incoming email text locally without third-party surveillance APIs.

Key Capabilities
  • App Auditor & Data Monitor: Inspects installed package permissions and highlights outliers sending background data.
  • Phishing Scanner: Evaluates email content against a specialized NLP classifier running via Hugging Face.
  • Malicious URL Inspection: Real-time heuristic checks against deceptive redirect patterns and suspect domains.
  • Incident Recovery Guides: Step-by-step walkthroughs to isolate devices and secure compromised credentials.
